# Railway deployment facts (read 2026-10-21; for the M5 deploy guide)
Gathered by a read-only research agent from Railway docs and forum threads; re-check before publishing a guide. UNVERIFIED = not confirmed in docs.

- Node: Railpack reads `RAILPACK_NODE_VERSION`, then `devEngines.runtime`, `engines.node`, `.nvmrc`... (https://railpack.com/languages/node/). Start command: the `start` script is auto-detected (same page). A missing build script: UNVERIFIED.
- Healthcheck: a path returning 2xx, default timeout 300 s, checked at deploy time only, from host `healthcheck.railway.app` (https://docs.railway.com/deployments/healthchecks). Railway injects `PORT`.
- `railway.json` config-as-code is deprecated (legacy files work until 2026-12-01; https://docs.railway.com/config-as-code/reference). Prefer dashboard settings.
- Postgres: add the service, then `DATABASE_URL=${{Postgres.DATABASE_URL}}` on the app (https://docs.railway.com/guides/express, https://docs.railway.com/variables/reference). Use the private URL; the public one is billed as egress. node-postgres SSL needs and pg-boss schema permissions: UNVERIFIED, test them.
- Proxy headers (https://docs.railway.com/networking/public-networking/specs-and-limits): `X-Real-IP` = client IP; `X-Forwarded-Proto` always https. `X-Forwarded-For` is not documented and staff/community disagree (https://station.railway.com/questions/security-critical-questions-on-edge-prox-8fddd775). The service therefore prefers `X-Real-IP` when `TRUSTED_PROXY=true`; after deploying, test with a spoofed header.
- Run ONE replica (no sticky sessions: https://docs.railway.com/deployments/scaling; our login limiter is in memory). pg-boss with several replicas: UNVERIFIED. Keep Serverless/sleep OFF (https://docs.railway.com/deployments/serverless), or webhooks can hit a sleeping service.
- Pricing (https://docs.railway.com/pricing/plans, https://docs.railway.com/pricing/free-trial): Free $0 with $1 credit/month; Hobby $5/month with $5 usage; trial up to 30 days with $5 once. Unverified accounts get restricted outbound access, which could block Salesforce/Shopify calls. $1/month probably does not cover an always-on app plus Postgres (inference).
- Domain: Networking > Generate Domain gives `*.up.railway.app` (not automatic); webhook URL = `https://<domain>/webhooks/shopify` (https://docs.railway.com/networking/domains/working-with-domains).
