## M3 — Admin UI
- [x] Connection setup + "Test connection"; recipe settings; log viewer with replay. _2026-10-21: a server-rendered operator admin at `/admin` inside the running service (`core/admin/`): sign-in, shops list/add, Salesforce connection form (secret never shown back) + Test connection, recipe controls (enable in dry-run, go live only after typing LIVE and with a stored connection, kill switch), validated settings form, paged filterable log viewer, failed-jobs list with Replay / Replay all (dead-letter redrive), audit trail of every admin action. Switched OFF unless `ADMIN_PASSWORD` is set. 49 mutations caught (test counts change; run `npm test`). This is a self-host operator page, NOT the embedded Shopify admin app (that belongs to the App Store phase, M7). Limits: one shared password, no roles, no 2FA; the login rate limiter and session revocation are in memory (one process); "replay" re-queues dead-lettered jobs within their 14-day retention, it cannot replay from a log entry (the log deliberately holds no payload)._
